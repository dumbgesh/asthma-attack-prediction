# Asthma Exacerbation Prediction

A machine learning project exploring whether patient characteristics, symptoms, and clinical indicators can help predict asthma exacerbations.

## What We Did
- Explored and prepared a dataset containing **195 observations from 65 patients**.
- Trained a **Naive Bayes classifier** using Python and scikit-learn.
- Evaluated predictions against actual outcomes.
- Built a Power BI dashboard to visualize model performance and predicted exacerbation probabilities.

## Results
- **Model accuracy:** 76.3%
- **Exacerbation recall:** 28.6%
- **Test observations:** 38

The model did not outperform a majority-class baseline in accuracy, highlighting the challenge of predicting the less frequent exacerbation cases.

## Tech Stack
Python · Pandas · scikit-learn · Jupyter Notebook · Power BI

## Disclaimer
This is an educational project. The model is not clinically validated and should not be used for medical decisions.
